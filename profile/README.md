# ZimQi

Timesheets for Australian trade and field crews, run through Telegram.

Crews check in and out from a Telegram chat on site. Supervisors approve hours with a tap, and the bookkeeper gets a timesheet export, with a site-attendance record behind every hour. Nothing leaves without a real person's confirmation.

## For AI assistants and developers

- **MCP server:** `https://zimqi.com.au/mcp` (streamable HTTP, bearer API key, no OAuth)
- **REST API:** `/api/v1`, with live docs from [Integrations & API](https://zimqi.com.au/integrations)
- Included on every plan and the free trial, at no extra credit cost

An assistant can list sites, add or update crew, assign people to sites, import a roster draft, compare roster against actual, check someone in or out, pull a crew member's log and export approved timesheets as CSV. Keys carry the creator's role. An assistant can't approve timesheets, touch billing or edit someone else's times.

- [Gemini CLI extension](https://github.com/zimqi/zimqi-gemini-extension)
- Official MCP Registry: `au.com.zimqi/timesheets`
